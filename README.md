# Tilevue support

Need help with [Tilevue](https://tilevue.com)? Open an issue here and we'll get back to you.

**[Open an issue →](../../issues/new/choose)**

## Before you post

- **Issues here are public.** Never share your email address, phone number, sign-in links or passwords.
- Your public page link (for example `tilevue.com/yourname`) is fine to share.
- Search the [existing issues](../../issues?q=is%3Aissue) first — someone may have asked already.

## What to choose

| | Use it for |
|---|---|
| 🐞 **Something isn't working** | An error, a button that does nothing, a card that looks wrong |
| ❓ **Question** | "How do I…?" |
| 💡 **Idea** | A new card or feature you'd like |
